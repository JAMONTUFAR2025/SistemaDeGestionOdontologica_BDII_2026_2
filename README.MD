# SOE Sistema
# ENTREGA EL 06 DE AGOSTO DEL 2026

Sistema desarrollado en Java 17 con JavaFX y Maven.

## Requisitos previos
- Java JDK 17 o superior.
- VS Code, IntelliJ IDEA o NetBeans.

## Cómo ejecutar el proyecto
1. Clona este repositorio:
   git clone <URL-de-tu-repositorio>
2. Abre la carpeta del proyecto en tu IDE preferido.
3. Espera a que Maven descargue las dependencias automáticamente.
4. Abre el archivo `src/main/java/application/AppLauncher.java` y presiona **Run**.
